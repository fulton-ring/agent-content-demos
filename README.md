# Agent content demos

Working demos and spikes behind Fulton Ring articles. Each project lives in its own folder, named after the proposal it answers, for example `k1-extraction-review-queue/`.

Every project folder has:

- `README.md`: what it shows, how to run it with one command, where the data comes from, the results, and what it doesn't show
- the code, sample inputs and outputs
- screenshots, and a short recording when the proposal asks for one

This repository is public. Projects use synthetic or public data only. No client documents, credentials, API keys or personal information.
