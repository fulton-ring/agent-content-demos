# HIFLD Next

HIFLD (Homeland Infrastructure Foundation-Level Data) datasets. 334 layers preserved from the federal HIFLD Open portal, which DHS shut down on 26 August 2025, published by Public Environmental Data Partners at https://hifld.publicenvirodata.org.

Each layer is a catalog under `hifld/`, with one sub-catalog per file and one collection per version. Every collection carries GeoParquet (preferred for analysis), PMTiles (for maps) and the original formats.
