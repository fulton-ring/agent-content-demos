# STORM North Atlantic, IBTrACS 1980-2025, seed 1

10,000 synthetic years refitted to IBTrACS 1980-2025. tracks.parquet has one point per 3-hourly fix; storm_text.zip is the same tracks in STORM's text format; manifest.json lists inputs, code and checksums.
