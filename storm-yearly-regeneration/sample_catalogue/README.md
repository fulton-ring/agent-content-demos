# Fulton Ring synthetic hurricane tracks

![tropical cyclone](https://img.shields.io/badge/tropical_cyclone-blue) ![hurricane](https://img.shields.io/badge/hurricane-blue) ![synthetic tracks](https://img.shields.io/badge/synthetic_tracks-blue) ![STORM](https://img.shields.io/badge/STORM-blue) ![IBTrACS](https://img.shields.io/badge/IBTrACS-blue)

10,000 years of synthetic North Atlantic tropical cyclone tracks from STORM, refitted to IBTrACS 1980-2025. One item per baseline and seed.

## Source

[https://github.com/fulton-ring/agent-content-demos/tree/main/storm-yearly-regeneration](https://github.com/fulton-ring/agent-content-demos/tree/main/storm-yearly-regeneration)

## Processing Notes

Release ibtracs-1980-2025-seed1: STORM's preprocessing and generator from github.com/NBloemendaal at pinned commits, refitted to IBTrACS v04r01 and ERA5 monthly means over the same seasons; see manifest.json.

## Citation

Bloemendaal, N. et al. (2020). Generation of a global synthetic tropical cyclone hazard dataset using STORM. Scientific Data 7, 40.
